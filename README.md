# Online Quiz System

## About the Project
A Java-based desktop application developed using Java Swing.

## Features
- User Login
- Multiple Choice Questions (MCQs)
- 5-Minute Timer
- Next and Previous Questions
- Automatic Result Calculation
- Pass/Fail Status
- Result History using File Handling

## Technologies Used
- Java
- Java Swing
- Eclipse IDE

## How to Run
1. Download the project.
2. Import it into Eclipse IDE.
3. Open Main.java.
4. Run the program.
